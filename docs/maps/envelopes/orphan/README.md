# Orphaned figures

Figures that no script in the pipeline writes any more. They were generated by an
earlier version of `erw/erw-11-private-public-envelopes.R` and committed by `6e46062`
before the file was renamed and corrected. Kept for provenance; **do not cite them**.

Nothing in the repository references these two paths. `paper/envelope-analysis-memo.md`
cites `mac_targeted.png` and `cdr_rate_sensitivity_panel.png` by bare filename, but its
header states its figures live in `paper/figures/` — and the copies there are different
files (Jun 25, committed in `ca301f4`, on the year-1 gross basis), not these. Those are
still live; leave them alone.

| file | generated | why it is orphaned |
|---|---|---|
| `mac_targeted.png` | 2026-07-10, `erw-11` §4 | Superseded, not wrong. A valid marginal-abatement-cost map on the equilibrium net-export basis, but for the **targeted** allocation. `erw-11` now leads the carbon case on uniform-20 and writes `../mac_uniform_20.png`. |
| `cdr_rate_sensitivity_panel.png` | 2026-07-10, `erw-11` §4 | Superseded **and incorrect**. Its CDR-rate sweep scaled the already-deducted net removal instead of gross, so panel (a) reports 2.68 Mha of public envelope at a 2× CDR rate where the correct figure is 12.56 Mha (uniform-20) or 5.90 Mha (targeted). See `../cdr_rate_sensitivity_panel_uniform_20.png`. |

## Why they were stranded

`erw-11` used to hardcode the targeted allocation in its public/VCM section and name
its outputs accordingly (`mac_targeted.png`, `cdr_rate_sensitivity_panel.png`). Commit
`cf255b5` re-led the carbon case on uniform-20 and made both filenames carry the
allocation suffix (`mac_${PUBLIC_ALLOC}.png`), so re-running the script writes new
files rather than overwriting the old ones. The originals had already been committed
and so survived as untracked-by-any-script artifacts.

If `PUBLIC_ALLOC` is ever switched back to `targeted`, `erw-11` will regenerate
`../mac_targeted.png` fresh. That is expected, and it will not be this file: this one
predates the gross-scaling fix to the CDR-rate lever.
